# Java Programming Practice

An independent Java learning collection spanning introductory syntax through object-oriented design, collections, file processing, concurrency, networking and reflection. It also includes completed exercises such as an ATM simulator, menu/order processing and a local registration/login application.

## Contents

`practice/` preserves the original lesson directories and source layout:

- `P1–P68`: statements, control flow, arrays, methods and small algorithmic cases
- `P69–P115`: classes, encapsulation, inheritance, interfaces and object-oriented exercises
- `P116–P150`: standard APIs, dates, lambdas, sorting/searching, regex, exceptions, collections and streams
- `P151–P174`: integrated exercises, file I/O, serialization, Properties/XML and logging
- `P175–P200`: threads, network communication, reflection, annotations, dynamic proxies and integrated applications

## Inputs and saved examples

Small text, image, XML, DTD and Properties fixtures remain beside their original exercises. Logging output, IDE templates, compiled files and installed library archives are excluded. The registration/login example does not include the original account store; use a fresh local store when studying that exercise.

## Usage and status

These are separate lesson projects rather than one application. Lesson structure and package declarations are retained. Machine-specific absolute paths in the repository copies use generic examples or placeholders. Configure a selected lesson and its inputs before running it. Some exercises write files, open sockets or create threads. No Java code was executed during repository preparation.

External libraries used by selected lessons include Apache Commons IO 2.18.0, dom4j 2.1.4, SLF4J/Logback and JUnit 4. Configure the required libraries for the lesson being opened; the original dependency JARs are not bundled here.

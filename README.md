# Programming Self-study

**Yuewei Xu | Independent programming practice**

A learning collection of completed exercises, notebooks, notes, and personal adaptations in Python, R, Java, SQL/MySQL, and Linux command-line tools.

## Using the collection

Start with a topic README, then choose an individual lesson, script, or notebook. Lesson-specific data and saved outputs remain beside their original exercises. Java lesson directories and R application layouts are preserved. Machine-specific paths in selected public copies use generic examples or placeholders.

These are independent learning exercises rather than one application. Dependencies and environment assumptions are documented within each topic. The code was not executed during this reorganisation.

## P5_P6 Web请求过程

1. 服务器渲染：服务器整合html于数据，统一返回给浏览器，网页源代码中有数据
2. 客户端渲染：第一次请求只返回html框架，后续请求才返回数据，网页源代码中有没数据，使用浏览器抓包工具搜寻数据

## P7_P8 HTTP协议

1. HTTP协议：Hyper Text Transfer Protocol(超文本传输协议),是用于从万维网(WWW:World Wide Web)服务器传输超文本到本地浏览器的传送协议,浏览器和服务器之间的数据交互遵守的就是HTTP协议
2. HTTP协议把一条消息分为三大块内容.无论是请求还是响应都是三块内容
    - 请求头
        - 格式
            1. 请求行 -> 请求方式（主要是get-得到/post-发送/put-更新/delete-删除），请求url地址，协议
            2. 请求头 -> 放一些服务器要使用的附加信息
            3. 请求体 -> 一般放一些请求参数
        - 重要内容
            1. User-Agent：请求载体的身份标识(用啥发送的请求)
            2. Referer：防盗链(这次请求是从哪个页面来的？反爬会用到)
            3. cookie：本地字符串数据信息(用户登录信息,反爬的token)
    - 响应头
        - 格式
            1. 状态行 -> 协议，状态码
            2. 响应头 -> 放一些客户端要使用的一些附加信息
            3. 响应体 -> 服务器返回的真正客户端要用的内容(HTML,json)等4
        - 重要内容
            1. cookie：本地字符串数据信息(用户登录信息,反爬的token)
            2. 各种神奇的莫名其妙的字符串(这个需要经验了,一般都是token字样,防止各种攻击和反爬)

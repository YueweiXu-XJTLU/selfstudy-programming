# 正则表达式
- 在线测试网站：YOUR_REGEX_TEST_URL
- 正则表达式
  - meta-char 元字符

| 字符                   | 匹配功能               | 
|----------------------|--------------------|
| `.`                  | 任意字符，除了`\n`        |
| `\d`                 | 数字                 |
| `\s`                 | 空白符(tab/space)     | 
| `\w`                 | 数字/字母/下划线          |
| `\n`                 | 换行符                |
| `\t`                 | 制表符(tab)           |
| `\b`                 | 表示单词的边界(本身不表示任何字符) |
|                      |                    |
| `\D`                 | not `\d`           |
| `\S`                 | not `\s`           |
| `\W`                 | not `\w`           |
| `\B`                 | not `\b`           |
|                      |                    |
| `^`                  | 字符串的开始             |
| `$`                  | 字符串的结尾             |
|                      |                    |
| `a\|b`               | a/b                |
| `(...)`              | 分组匹配               |
| `(?P<pattern_name>)` | 命名分组               |
| `[abc]`              | a/b/c              |
| `[^abc]`             | 不是a/b/c            |

  - 量词

|字符|匹配功能| 
|---|---|
|`*`|>=0|
|`+`|>=1|
|`?`|0/1|
|`{m}`|=m|
|`{m,}`|>=m|
|`{m, n}`|>=m & <=n|

  - 匹配规则

|字符|匹配功能| 
|---|---|
|`.*`|贪婪匹: `*?`指任意次数|
|`.*?`|惰性匹配: `*?`指使得匹配次数尽量小|

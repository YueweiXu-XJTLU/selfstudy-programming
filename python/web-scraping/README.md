# Python Web Scraping and Concurrency Practice

An independent learning collection covering HTTP requests, structured-page extraction, regular expressions, thread/process pools and asynchronous I/O.

## Contents

- `Formal_Study/`: topic-by-topic scripts, explanatory notes, a small HTML fixture and selected tabular results
- `Just_a_Try/`: introductory requests and Beautiful Soup exercises

## Saved results

Selected CSV files contain movie/book ranking and vegetable-price examples. These are historical practice outputs, not current datasets. Website-specific input values and local paths in the public scripts have been replaced with placeholders.

## Usage and status

The scripts are independent exercises. Dependencies vary by file and include requests, Beautiful Soup, lxml, aiohttp, aiofiles and cryptography utilities; media examples also use ffmpeg. Scripts use YOUR_* placeholders for target URLs, request values, proxies, browser headers and local tool/output paths. Supply appropriate values for a site you may access before running them. Some examples also expect files outside this collection. Website layouts and endpoints may have changed. No scripts or network requests were executed during repository preparation.

## Attribution

This repository records tutorial-guided practice and adaptations rather than a production crawler or a claim to the originality of standard examples. Downloaded books, audiovisual content, comments and account-dependent exercises are outside the repository. Respect the access rules and terms of any service before running an example.

# Python Programming Practice

An independent Python study collection progressing from language basics to object-oriented programming, file processing, threading and sockets.

## Contents

- `Basic_Learning/Stage1/`: expressions, control flow, functions, containers, files and small utility modules
- `Basic_Learning/Stage2/Chapter1_OOP/`: classes, inheritance and a sales-record aggregation exercise
- `Basic_Learning/Stage3/Chapter2_advanced/`: additional object-oriented, threading, socket and filesystem exercises

## Data and saved outputs

Small teaching fixtures, synthetic sales records and file-processing examples are preserved beside their original scripts. These are practice datasets, not research or personal customer records.

## Usage and status

The files are independent exercises and retain their original names and layout. Run a chosen exercise from its chapter directory after reviewing its inputs. Some examples rely on their original environment, interact with files, or start local client/server sockets. They were not executed during repository preparation.

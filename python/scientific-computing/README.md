# Python Scientific Computing Practice

Worked notebooks exploring numerical arrays, tabular data processing, plotting and basic tensor operations during independent Python study.

## Contents

- [NumPy](notebooks/NumPy.ipynb): array creation, indexing, reshaping and numerical operations
- [Pandas](notebooks/Pandas.ipynb): Series, DataFrames, indexing and data manipulation
- [Matplotlib](notebooks/Matplotlib.ipynb): plotting styles, axes and figure configuration
- [PyTorch](notebooks/PyTorch.ipynb): basic tensors and device selection
- [scikit-learn notes](notebooks/SKlearn.ipynb): an introductory workflow outline with no implementation yet

## Saved outputs and inputs

The original notebook outputs, `Data.csv`, `test1.svg` and `test2.png` are retained in `notebooks/`. Open a notebook with that directory as the working location to resolve its local example files.

## Status and attribution

These are tutorial-guided exercises and personal study notes, not a benchmark or novel library. Dependencies include Jupyter, NumPy, Pandas, Matplotlib and PyTorch. The PyTorch example preserves its original CUDA device setting, which may need an appropriate machine. No notebooks were executed during repository preparation.

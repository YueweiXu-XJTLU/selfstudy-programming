# Python Sorting Algorithms

Ten classical sorting implementations collected during independent Python study: bubble, selection, insertion, Shell, merge, quick, heap, counting, bucket and radix sorting.

## Contents

- `sorting/`: original Python implementations and embedded example inputs
- [Study overview](sorting/0_Sort_Algorithms.md): algorithm list and supporting diagrams

## Learning focus

Comparison-based sorting, recursive decomposition, heap operations and integer sorting. Each script preserves its original example and execution block. These files have been inspected and organized, but were not executed during repository preparation.

## Attribution

This is a personal learning record of standard algorithms, informed by the RUNOOB tutorial linked in the study overview. It does not claim novel sorting algorithms. Original study notes and code are preserved unchanged; linked tutorial illustrations remain supporting reference material.

[RUNOOB: Ten Classic Sorting Algorithms](https://www.runoob.com/w3cnote/ten-sorting-algorithm.html). The files are study exercises and retain their original lesson content.

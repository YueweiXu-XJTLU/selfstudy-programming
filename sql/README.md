# SQL and MySQL Study

SQL exercises and annotated MySQL notes covering database setup, DDL, DML, DQL, DCL, joins, subqueries, transactions, indexes, SQL optimisation, views, stored routines, and triggers.

## Materials

- [MySQL study notes](mysql-notes.md): concepts, syntax, examples, and operational notes
- [SQL query practice](mysql-query-practice.md): archived commands and exercises in SQL code blocks

The source materials are Markdown study records, not a single executable SQL migration. They retain their original examples, ordering, and Chinese explanations. Local MySQL passwords, password examples, one installation path and identity/contact fields in practice rows were masked in these repository copies; the original files remain untouched. Two image references in the source notes point to assets absent from the original collection and are marked as unavailable in this copy. No SQL commands were executed during this organisation.

## Learning reference

These exercises follow [Heima Programmers' MySQL course on Bilibili](https://www.bilibili.com/video/BV1Kr4y1i7ru/), with independent notes and worked queries. They document tutorial-guided practice rather than an original database product.

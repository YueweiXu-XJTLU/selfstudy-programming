# Self-study - R programming, visualization, and Shiny

**Yuewei Xu | Independent programming practice**

A collection of annotated R exercises covering data structures, file formats, descriptive statistics, regression, base graphics, ggplot2, and Shiny. A small Java example demonstrates calling R through Rserve.

## Contents

- `R_Study/`: fundamentals, CSV/Excel/XML/JSON examples, statistical exercises, saved plots, and Java integration
- `R_Plots/`: ggplot2 examples and extended plotting practice using built-in and gcookbook datasets
- `R_Shiny/`: single-file and multi-file applications, interface layouts, widgets, and reactive output

The files are study exercises, not one sequential application. Open an individual R script or run a Shiny application from its own directory. Packages used across the collection include ggplot2, gcookbook, plyr, shiny, bslib, bsicons, XML, rjson, xlsx, and Rserve. Some examples retain machine-specific font references; personal working and library paths use placeholders. Font and Java dependency binaries are not bundled. The local database connection example and deployment records are omitted.

The exercises build on standard package examples and learning resources, including Runoob-style file examples and gcookbook data. They are presented as annotated learning and adaptation, not novel algorithms. Apart from path redaction in repository copies, the study scripts and saved outputs are preserved; no runtime validation is claimed.

***This repository contains educational practice and is not a production software package.***
